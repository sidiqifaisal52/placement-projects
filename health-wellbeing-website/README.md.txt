# Health and Well-being Website

This website was developed as part of a first-year group project for the Web Design and Development module at the University of Westminster.

## My Contribution

My assigned responsibility was to design and develop:

* The Feedback page
* The Team page
* Supporting page-editor information
* HTML validation evidence

## Features

* Health and well-being programme information
* Ratings and reviews
* User feedback form
* Form validation using JavaScript
* Character counter for user comments
* Responsive and accessible page structure

## Technologies Used

* HTML
* CSS
* JavaScript

## Skills Developed

* Web development

* Problem-solving
